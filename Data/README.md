## Datos

---

Para este trabajo se utilizo el dataset CICIDS-2017 creado por el **Canadian Institute for Cybersecurity (CIC)**. Debido al tamaño del dataset original los archivos no pueden ser incluidos directamente en este repositorio.

Los datos pueden descargarse desde el siguiente link: https://www.kaggle.com/datasets/martinchogodoy/cicids-2017/data 

Conduce a un repositorio de la pagina Kaggle creado para este trabajo.

Como parte de la tarea se tuvieron que preprocesar los datos: Se eliminaron filas duplicadas, se trataron valores infinitos y faltantes, se agruparon etiquetas en 7 clases, se normalizaron las features, se aplicó SMOTE, etc. Todos estos pasos fueron documentados en el proceso.
